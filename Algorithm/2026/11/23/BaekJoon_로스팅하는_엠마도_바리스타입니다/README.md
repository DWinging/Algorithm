### BaekJoon Platinum Ⅴ [로스팅하는 엠마도 바리스타입니다](https://www.acmicpc.net/problem/15647) (Java)

> **문제 번호:** 15647 <br>
> **날짜:** 2026년 11월 23일 <br>
> **알고리즘:** 트리, 트리에서의 DP <br>
> **언어:** Java <br>
> **핵심 키워드:** 트리에서의 DP

## 📌 문제 개요

- 농장 `N`개가 정점 `1`부터 `N`까지로 표현된 트리로 연결되어 있으며, `1 ≤ N ≤ 300,000`이다.
- `N - 1`개의 간선마다 양 끝점 `u`, `v`와 이동 거리 `d`가 주어지고, `1 ≤ d ≤ 5`이다.
- 두 농장 사이의 거리는 유일한 경로에 있는 간선 가중치의 합이다.
- 각 농장을 기준으로 다른 모든 농장까지의 거리 합을 구한다.
- 정점 번호 순서대로 거리 합을 한 줄에 하나씩, 총 `N`줄 출력한다.

---

## 💡 풀이 핵심 (Core Logic)

### 1. 서브트리 크기와 서브트리 내부 거리 합 계산

간선을 양방향 인접 리스트 `arr`에 저장하고, `settingTree(arr, cnt, dp, 0, 1)`로 정점 `1`을 루트로 하는 DFS를 수행한다. 부모로 돌아가는 간선을 제외하고 자식을 탐색한다.

`cnt[node]`는 자신을 포함한 서브트리의 정점 수이고, 이 단계의 `dp[node]`는 `node`에서 자신의 서브트리 정점들까지의 거리 합이다. 현재 정점을 포함하도록 `cnt[node]`를 먼저 1 증가시키고, 자식의 탐색이 끝나면 다음 값을 누적한다.

```text
cnt[node] += cnt[child]
dp[node] += dp[child] + d * cnt[child]
```

부모에서 자식 서브트리의 모든 정점으로 가려면 길이 `d`인 간선을 각각 한 번씩 더 지나야 하므로 `d * cnt[child]`가 추가된다. 첫 DFS가 끝나면 `dp[1]`은 정점 `1`에서 전체 정점까지의 거리 합이다.

### 2. 루트를 옮기며 전체 거리 합 갱신

`solve`는 부모의 전체 거리 합을 이용해 자식의 전체 거리 합을 구한다. 부모 `p`에서 자식 `node`로 기준 정점을 옮기면, `node`의 서브트리에 속한 `cnt[node]`개 정점까지의 거리는 간선 길이 `w`만큼 줄어든다. 나머지 `n - cnt[node]`개 정점까지의 거리는 각각 `w`만큼 늘어난다.

```text
dp[node] = dp[p] + w * (n - 2 * cnt[node])
```

따라서 정점 하나의 전체 거리 합을 상수 시간에 갱신할 수 있다. `cnt`는 최초 루트 `1`을 기준으로 계산한 값을 그대로 유지하고, `dp`만 전체 트리에 대한 거리 합으로 덮어쓴다. 부모의 값이 먼저 갱신된 뒤 자식으로 내려가므로 전이에 필요한 값이 항상 준비되어 있다.

최초 호출은 `solve(arr, cnt, dp, 1, 1, 0, n)`이다. 이때 부모와 현재 정점이 모두 `1`이고 `w = 0`이므로, 첫 DFS에서 구한 `dp[1]`이 그대로 유지된다.

### 3. 정점 번호 순서대로 결과 출력

두 번째 DFS가 끝나면 `dp[i]`는 정점 `i`에서 다른 모든 정점까지의 거리 합이다. `1`부터 `n`까지 순회하며 `StringBuilder`에 결과를 모아 출력한다.

길이 `5`인 간선으로 이루어진 일자형 트리의 끝점에서는 거리 합이 `5 * n * (n - 1) / 2`까지 커질 수 있으므로 `dp`와 간선 거리를 `long`으로 저장한다. 가중치 곱셈도 `long`으로 수행된다. 정점이 하나뿐이면 간선이 없고 거리 합은 `0`이다.

### 시간 복잡도

- **시간:** `O(n)` — 인접 리스트 구성과 두 번의 DFS, 결과 출력에서 정점과 간선을 선형으로 처리한다.
- **공간:** `O(n)` — 인접 리스트, `cnt`, `dp`, 출력 버퍼와 최대 깊이 `n`의 재귀 호출 스택을 사용한다.
- 두 DFS 모두 재귀로 구현되어 있어, 일자형 트리에서는 실행 환경의 스택 크기에 영향을 받는다.
- `n`: 농장 수
- `d`, `w`: 부모와 자식을 연결하는 간선의 길이
