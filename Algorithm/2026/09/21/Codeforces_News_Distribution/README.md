### Codeforces 1400 [News Distribution](https://codeforces.com/problemset/problem/1167/C) (Java)

> **날짜:** 2026년 09월 21일 <br>
> **알고리즘:** 분리 집합 <br>
> **언어:** Java <br>
> **핵심 키워드:** Union-Find

## 📌 문제 개요

- `n`명의 사용자가 `m`개의 친구 그룹에 속해 있다.
- 같은 그룹에 속한 두 사용자는 친구이며, 친구 관계를 따라 뉴스가 계속 전달된다.
- 각 그룹의 인원 수 합은 최대 `5 × 10^5`이다.
- 각 사용자가 처음 뉴스를 전파했을 때 최종적으로 뉴스를 알게 되는 사용자 수를 구한다.

---

## 💡 풀이 핵심 (Core Logic)

### 1. 사용자별 분리 집합 초기화

각 사용자를 자신의 부모로 초기화하고 집합 크기를 `1`로 둔다. 뉴스가 전달되는 전체 연결 요소의 크기가 곧 정답이므로, 루트마다 현재 집합의 사용자 수를 함께 관리한다.

### 2. 그룹의 모든 사용자를 하나의 집합으로 병합

빈 그룹은 건너뛰고, 인원이 있는 그룹은 첫 번째 사용자 `a`를 기준으로 나머지 사용자 `b`를 차례로 `union`한다. 같은 그룹의 사용자들이 모두 하나의 연결 요소가 되며, 여러 그룹이 사용자를 공유하면 해당 연결 요소들도 자연스럽게 합쳐진다.

`union`에서는 두 루트를 찾은 뒤 크기가 작은 집합을 큰 집합 아래에 연결하고, 새 루트의 `cnt`에 두 집합의 크기를 합산한다. `find`는 재귀적으로 루트를 찾으면서 경로를 압축해 이후 탐색 비용을 줄인다.

### 3. 각 사용자가 속한 집합의 크기 출력

모든 그룹을 처리한 뒤 각 사용자 `i`의 루트 `p`를 찾고 `cnt[p]`를 출력한다. 같은 연결 요소에 속한 사용자는 어느 한 명이 뉴스를 시작해도 모두에게 전달되므로 동일한 값을 갖는다.

### 시간 복잡도

- `n`: 사용자 수
- `K`: 모든 그룹의 인원 수 합
- 경로 압축과 크기 기준 병합을 사용하므로 전체 시간 복잡도는 `O((n + K) α(n))`, 공간 복잡도는 `O(n)`이다.
