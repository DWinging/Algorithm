> **날짜:** 2026년 9월 13일 <br>
> **알고리즘:** 그리디, 두 포인터, 자료구조<br>
> **언어:**  Java <br>
> **핵심 키워드:** 그리디, 두 포인터, 자료구조

## 📌 문제 개요

* 위치 `1`에서 시작하며 초기 점프력은 `1`이다.
* 경로에는 착지할 수 없는 여러 장애물 구간이 존재한다.
* 각 위치에 존재하는 파워업을 획득하면 점프력이 증가한다.
* 위치 `L`까지 도달하기 위해 필요한 **최소 파워업 획득 개수**를 구한다.
* 도달할 수 없는 경우 `-1`을 출력한다.

---

## 💡 풀이 핵심 (Core Logic)

### 1. 장애물과 파워업을 순차적으로 탐색한다

장애물과 파워업은 모두 위치 기준으로 정렬되어 주어진다.

현재 장애물의 시작점 이전에 존재하는 파워업을 모두 우선순위 큐에 저장한다.

### 2. 장애물을 넘기 위한 최소 점프력을 계산한다

장애물이 `[l, r]`이라면 장애물 직전 위치 `l - 1`에서 `r + 1`까지 이동해야 한다.

따라서 필요한 최소 점프력은 다음과 같다.

`r - l + 2`

### 3. 점프력이 부족하면 가장 큰 파워업부터 사용한다

현재 점프력으로 장애물을 넘을 수 없다면 지금까지 획득 가능한 파워업 중 가장 큰 값을 우선 사용한다.

파워업 하나를 사용할 때마다 획득 개수를 증가시키며, 장애물을 넘을 수 있을 때까지 반복한다.

큰 파워업부터 사용하는 것이 동일한 점프력을 확보하는 데 필요한 파워업 개수를 최소화한다.

### 4. 장애물을 넘을 수 없으면 탐색을 종료한다

사용 가능한 모든 파워업을 사용한 이후에도 필요한 점프력에 도달하지 못하면 `L`까지 이동할 수 없으므로 `-1`을 반환한다.

### 5. 시간 복잡도

각 장애물과 파워업을 한 번씩 순차 탐색하며, 파워업은 우선순위 큐에 한 번 삽입되고 최대 한 번 제거된다.

전체 시간 복잡도는 `O((n + m) log m)`이다.
