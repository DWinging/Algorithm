### Codeforces 1500 [Magic Powder - 2](https://codeforces.com/problemset/problem/670/D2) (Java)

> **날짜:** 2026년 09월 22일 <br>
> **알고리즘:** 이분 탐색 <br>
> **언어:** Java <br>
> **핵심 키워드:** 파라매트릭 서치

## 📌 문제 개요

- 쿠키 하나를 만들려면 `n`가지 재료가 모두 필요하며, 각 재료별 필요량 `a_i`가 주어진다.
- 현재 보유한 각 재료의 양은 `b_i`이다.
- 마법 가루 `k`그램은 원하는 재료를 같은 양으로 바꾸어 부족분을 채울 수 있다.
- 보유 재료와 마법 가루를 사용해 만들 수 있는 쿠키의 최대 개수를 구한다.

---

## 💡 풀이 핵심 (Core Logic)

### 1. 쿠키 개수를 기준으로 탐색 범위 설정

만들 수 있는 쿠키 수를 `mid`로 두고 `0`부터 문제의 최대 정답 범위인 `2,000,000,000`까지 이분 탐색한다. 쿠키를 더 많이 만들수록 필요한 마법 가루가 줄어들지 않으므로, 특정 개수가 가능하면 그보다 작은 개수도 모두 가능하다는 단조성이 성립한다.

### 2. 목표 개수에 필요한 마법 가루 계산

각 재료에 대해 `a_i * mid - b_i`를 계산하고, 값이 양수인 경우에만 부족분으로 합산한다. 합계가 `k`를 초과하면 해당 개수는 만들 수 없으므로 나머지 재료를 확인하지 않고 즉시 계산을 중단한다.

### 3. 가능한 최대 개수 찾기

필요한 마법 가루가 `k` 이하이면 더 많은 쿠키를 확인하기 위해 `left = mid + 1`로 이동하고, 초과하면 `right = mid - 1`로 이동한다. 탐색이 끝났을 때 마지막으로 가능했던 경계인 `right`를 반환한다.

### 시간 복잡도

- `n`: 재료의 종류 수
- `M`: 탐색하는 쿠키 개수의 상한 (`2,000,000,000`)
- 각 판정에 모든 재료를 최대 한 번 확인하므로 시간 복잡도는 `O(n log M)`이다.
- 재료별 필요량과 보유량을 저장하므로 공간 복잡도는 `O(n)`이다.
