### Codeforces 1600 [Sending a Sequence Over the Network](https://codeforces.com/problemset/problem/1741/E) (Java)

> **문제 번호:** 1741E <br>
> **날짜:** 2026년 10월 23일 <br>
> **알고리즘:** DP <br>
> **언어:** Java <br>
> **핵심 키워드:** DP

## 📌 문제 개요

- 원래 수열을 연속된 구간들로 나누며, 각 원소는 정확히 한 구간에 속한다.
- 각 구간의 길이를 해당 구간의 왼쪽 또는 오른쪽에 적어 전송 수열을 만든다.
- 여러 테스트 케이스에서 전송 수열의 길이와 원소들이 주어진다.
- 주어진 수열이 이 방식으로 만들어질 수 있는지 각 테스트 케이스마다 판별한다.

---

## 💡 풀이 핵심 (Core Logic)

### 1. 유효한 접두사의 끝을 기록

`dp[i]`는 앞의 `i`개 원소를 길이 표시가 붙은 구간들로 나눌 수 있는지를 나타낸다. 빈 접두사는 가능하므로 `dp[0] = true`로 시작한다. 입력 순서대로 각 위치를 살펴보면 새로운 구간이 끝나는 위치를 앞에서부터 갱신할 수 있다.

### 2. 길이 표시가 구간 왼쪽에 있는 경우

`dp[i]`가 참이고 `arr[i]`개 원소가 뒤에 남아 있으면, `arr[i]`를 길이 표시로 보고 그 뒤의 원소들을 하나의 구간으로 묶는다. 따라서 `dp[i + arr[i] + 1]`을 참으로 만든다. 앞부분이 유효하고 표시된 길이만큼의 원소가 있어야 이 구간을 추가할 수 있다.

### 3. 길이 표시가 구간 오른쪽에 있는 경우

`arr[i] <= i`이고 `dp[i - arr[i]]`가 참이면, `i` 앞의 `arr[i]`개 원소를 한 구간으로 묶고 현재 원소를 그 길이 표시로 사용한다. 이때 `dp[i + 1]`을 참으로 만든다. 모든 위치를 처리한 뒤 `dp[n]`으로 수열 전체를 구성할 수 있는지 판별한다.

### 시간 복잡도

각 테스트 케이스에서 입력과 DP 배열을 한 번씩 순회하므로 `O(n)`이다. 전체 테스트 케이스에서는 수열 길이의 합을 `N`이라 할 때 `O(N)`이다.

- `n`: 한 테스트 케이스의 전송 수열 길이
- `N`: 모든 테스트 케이스의 전송 수열 길이 합
