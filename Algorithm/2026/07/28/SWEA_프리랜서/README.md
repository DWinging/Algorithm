## 📌 문제 개요

* **설명:** 여러 작업 요청의 시작일, 종료일, 수행 금액이 주어질 때, 일정이 서로 겹치지 않도록 작업을 선택하여 얻을 수 있는 최대 금액을 구하는 문제이다.

* 하나의 요청을 선택하면 해당 요청의 시작일부터 종료일까지 다른 요청을 수행할 수 없다.

* 이전 작업의 종료일과 다음 작업의 시작일이 같은 경우에도 일정이 겹치므로, 다음 작업은 이전 작업의 종료일보다 늦게 시작해야 한다.

```text
이전 작업 종료일 < 다음 작업 시작일
```

* 모든 요청을 수행할 필요는 없으며, 서로 겹치지 않는 요청들로 구성된 일정 중 전체 금액의 합이 가장 큰 경우를 구한다.

* **제약 조건:**

  * 테스트 케이스 수는 최대 `10`이다.
  * 요청의 개수 `N`은 최대 `500`이다.
  * 전체 기간 `M`은 최대 `10,000`일이다.
  * 각 요청의 시작일과 종료일은 `0` 이상 `10,000` 이하이다.
  * 각 요청의 수행 금액은 `0` 이상 `10,000` 이하이다.

## 💡 풀이 핵심 (Core Logic)

### 1. 작업을 시작일 기준으로 정렬

* 현재 작업 이후에 수행할 수 있는 작업을 순서대로 탐색하기 위해 요청을 시작일 기준으로 오름차순 정렬한다.

* 시작일이 같은 경우에는 종료일을 기준으로 오름차순 정렬한다.

```java
Arrays.sort(arr, 0, n, (a, b) -> {
    if (a[0] != b[0]) return a[0] - b[0];
    return a[1] - b[1];
});
```

* 정렬 후에는 현재 작업보다 뒤에 있는 요청만 확인하면 되므로, 이미 지나간 요청을 다시 탐색할 필요가 없다.

### 2. 현재 작업을 선택한 상태를 DP로 정의

* `dp[i]`는 `i`번 작업을 반드시 선택했을 때, 해당 작업부터 이후에 얻을 수 있는 최대 금액을 의미한다.

```text
dp[i] = i번 작업을 선택했을 때 얻을 수 있는 최대 금액
```

* 현재 작업의 금액은 항상 포함되며, 이후 수행 가능한 작업 중 가장 큰 결과를 추가한다.

```text
dp[i] = 현재 작업 금액 + 이후 선택 가능한 작업의 최대 dp 값
```

### 3. 일정이 겹치지 않는 다음 작업 탐색

* 현재 작업의 종료일보다 시작일이 늦은 작업만 다음 작업으로 선택할 수 있다.

```java
arr[next][0] > arr[idx][1]
```

* 조건을 만족하는 모든 다음 작업에 대해 최대 금액을 비교한다.

```java
int cost = 0;

for (int next = idx + 1; next < n; next++) {
    if (arr[next][0] > arr[idx][1]) {
        cost = Math.max(cost, dfs(next, n));
    }
}
```

* 이후 선택 가능한 작업이 없다면 현재 작업의 금액만 반환한다.

### 4. 탑다운 DP로 중복 계산 제거

* 서로 다른 작업 경로에서도 동일한 작업을 다음 작업으로 선택할 수 있다.

* 동일한 작업을 선택한 이후의 최적 결과는 이전에 어떤 작업을 수행했는지와 관계없이 동일하다.

* 따라서 이미 계산한 `dp[idx]`가 존재하면 이후 일정을 다시 탐색하지 않고 저장된 값을 반환한다.

```java
if (dp[idx] != -1) {
    return dp[idx];
}
```

* 이를 통해 순수 백트래킹에서 반복되는 하위 탐색을 제거할 수 있다.

```java
private static int dfs(int idx, int n) {
    if (dp[idx] != -1) {
        return dp[idx];
    }

    int cost = 0;

    for (int next = idx + 1; next < n; next++) {
        if (arr[next][0] > arr[idx][1]) {
            cost = Math.max(cost, dfs(next, n));
        }
    }

    return dp[idx] = arr[idx][2] + cost;
}
```

### 5. 모든 작업을 시작점으로 확인

* 최적 일정이 반드시 첫 번째 작업에서 시작한다는 보장은 없다.

* 따라서 각 작업을 첫 번째 작업으로 선택했을 때의 결과를 모두 확인한다.

```java
int result = 0;

for (int i = 0; i < n; i++) {
    result = Math.max(result, dfs(i, n));
}
```

* 모든 시작점의 결과 중 가장 큰 값이 최종 답이 된다.

### 6. 시간 복잡도

* 각 작업의 `dp` 값은 한 번만 계산한다.

* 하나의 작업을 계산할 때 뒤에 있는 작업을 최대 `N`개 확인한다.

```text
시간 복잡도: O(N²)
공간 복잡도: O(N)
```

* `N`은 최대 `500`이므로 제한 범위 내에서 충분히 처리할 수 있다.
