### LeetCode 3584 [Maximum Product of First and Last Elements of a Subsequence](https://leetcode.com/problems/maximum-product-of-first-and-last-elements-of-a-subsequence/description/) (Java)

> **날짜:** 2026년 07월 01일 <br>
> **알고리즘:** DP, 두 포인터 <br>
> **언어:**  Java <br>
> **핵심 키워드:** DP, 두 포인터

## 📌 문제 개요

* 주어진 정수 배열 `nums`에서 길이가 $m$인 임의의 부분 수열(Subsequence)을 구성할 때, 해당 부분 수열의 **첫 번째 원소와 마지막 원소의 곱이 가질 수 있는 최댓값**을 구하는 최적화 문제다.
* 부분 수열의 특성상 원소들의 상대적 순서는 유지되어야 하므로, 첫 번째 원소의 인덱스를 $i$, 마지막 원소의 인덱스를 $j$라고 할 때 고른 두 원소 사이에 최소 $m-2$개의 원소가 존재할 수 있어야 한다. 즉, 두 인덱스는 **$j - i \ge m - 1$** 조건을 만족해야 한다.
* 곱의 최댓값을 구해야 하므로 양수 간의 곱뿐만 아니라, 음수와 음수의 곱으로 인해 발생할 수 있는 최댓값 케이스를 함께 고려해야 하며 연산 과정에서의 정수 오버플로우 처리가 요구된다.

---

## 💡 풀이 핵심 (Core Logic)

### 1. 구간 제약과 다이내믹 프로그래밍 (Suffix Accumulation)

* 특정 원소 $nums[i]$를 첫 번째 원소로 선택했을 때, 마지막 원소가 될 수 있는 범위는 인덱스 $i + m - 1$부터 배열의 끝($n-1$)까지다.
* 이 유효 범위 내에서 발생할 수 있는 곱의 최댓값을 빠르게 찾기 위해, 뒤에서부터 역방향으로 순회하며 해당 시점까지의 최솟값과 최댓값을 누적 기록하는 DP 테이블(또는 접미사 배열)을 구성한다.
* 배열 작성이 완료되면 정방향으로 순회하며 현재 원소와 유효 시작 지점의 누적 최솟값/최댓값을 각각 곱해 실시간으로 최댓값을 갱신한다.

### 2. 투 포인터와 슬라이딩 윈도우 기반 동적 갱신 ($O(1)$ Space)

* 마지막 원소의 인덱스를 $j$라고 가정하면, $j$가 선택될 수 있는 최초의 위치는 $m - 1$이다. 이 시점에서 첫 번째 원소가 될 수 있는 후보 인덱스는 $0$부터 $j - m + 1$까지 확장된다.
* $j$를 $m - 1$부터 $n - 1$까지 한 칸씩 전진시킬 때마다, 첫 번째 원소의 후보군에 새롭게 진입하는 인덱스(`idx = j - m + 1`)는 단 하나씩만 추가된다.
* 따라서 별도의 2차원 배열 없이 단 두 개의 변수(`minVal`, `maxVal`)만 유지하며 새로 진입하는 원소로 최솟값과 최댓값을 동적 갱신하고, 현재 $nums[j]$와 즉시 연산하여 공간 복잡도를 최적화한다.

## 📊 풀이 방식 비교 ( 접미사 누적 배열 vs 투 포인터 동적 갱신 )

| 비교 항목 | 접미사 누적 배열 (DP 계열) | 투 포인터 동적 갱신 (슬라이딩 윈도우) |
| --- | --- | --- |
| **알고리즘 성격** | 공간 기반 데이터 사전 연산 및 참조 | 단일 포인터 이동에 따른 상태 동적 제어 |
| **시간 복잡도** | $O(N)$ (역방향 1회, 정방향 1회 총 2회 순회) | $O(N)$ (인덱스 $m-1$부터 단 1회 순회) |
| **공간 복잡도** | $O(N)$ (`[n][2]` 크기의 2차원 공간 할당 필요) | $O(1)$ (상태 저장을 위한 변수 몇 개로 제한) |
| **메모리 오버헤드** | 대규모 데이터 입력 시 힙 영역 객체 할당 및 가비지 컬렉션 부담 증가 | 기본 원시 타입 변수만 사용하여 메모리 할당 비용 전무 |
| **데이터 접근 흐름** | 역방향 루프로 값을 채운 후 정방향 루프에서 인덱스 점프 참조 | 포인터 전진에 따라 새로운 진입 원소만 실시간 흡수 |
| **최종 평가** | 직관적 분할이 가능하나 메모리와 루프 횟수 측면에서 차선책 | 불필요한 공간과 연산을 원천 배제하여 런타임 효율을 극대화한 최적의 방식 |
