### LeetCode 1361 [Validate Binary Tree Nodes](https://leetcode.com/problems/validate-binary-tree-nodes/description/) (Java)

> **날짜:** 2026년 8월 18일 <br>
> **알고리즘:** 트리, 그래프 탐색<br>
> **언어:**  Java <br>
> **핵심 키워드:** 트리, BFS, DFS

## 📌 문제 개요

* `0`부터 `n - 1`까지 번호가 매겨진 `n`개의 노드가 주어진다.
* 각 노드 `i`의 왼쪽 자식과 오른쪽 자식은 각각 `leftChild[i]`, `rightChild[i]`로 주어진다.
* 자식이 존재하지 않는 경우 값은 `-1`이다.
* 주어진 모든 노드가 정확히 하나의 유효한 이진 트리를 구성하는지 확인한다.

---

## 💡 풀이 핵심 (Core Logic)

### 1. 각 노드의 부모 존재 여부 확인

* 이진 트리에서 루트를 제외한 모든 노드는 정확히 하나의 부모를 가져야 한다.
* `leftChild`, `rightChild`를 순회하며 각 노드가 자식으로 등장했는지 확인한다.
* 이미 자식으로 등장한 노드가 다시 등장한다면 두 개 이상의 부모를 가지므로 `false`를 반환한다.

### 2. 루트 노드 확인

* 한 번도 자식으로 등장하지 않은 노드는 부모가 없는 노드이므로 루트 후보가 된다.
* 유효한 이진 트리는 루트가 정확히 하나 존재해야 한다.
* 루트 후보가 없거나 두 개 이상 존재하면 `false`를 반환한다.

### 3. 루트에서 전체 노드 탐색

* 찾은 루트에서 BFS를 수행하여 연결된 모든 노드를 탐색한다.
* 탐색한 노드 수가 `n`과 동일하면 모든 노드가 하나의 트리에 포함된 것이다.
* 탐색하지 못한 노드가 존재하면 분리된 트리 또는 별도의 사이클이 존재하므로 `false`를 반환한다.

---

```text
시간 복잡도: O(n)
공간 복잡도: O(n)
```

* 핵심은 **각 노드가 최대 하나의 부모만 가지는지 확인하고, 유일한 루트에서 모든 노드에 도달할 수 있는지 검증하는 것**이다.
