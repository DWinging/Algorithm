### LeetCode 1657 [Determine if Two Strings Are Close](https://leetcode.com/problems/determine-if-two-strings-are-close/description/) (Java)

> **날짜:** 2026년 8월 17일 <br>
> **알고리즘:** 문자열, 정렬 <br>
> **언어:**  Java <br>
> **핵심 키워드:** 문자열, 정렬

## 📌 문제 개요

* 두 문자열 `word1`, `word2`가 주어진다.
* 두 문자열은 다음 두 연산을 원하는 만큼 수행할 수 있다.

  * 문자열 내 임의의 두 문자의 위치를 교환한다.
  * 문자열에 존재하는 두 문자를 선택하여 모든 등장 위치를 서로 치환한다.
* 위 연산을 통해 한 문자열을 다른 문자열로 변환할 수 있으면 `true`, 그렇지 않으면 `false`를 반환한다.

---

## 💡 풀이 핵심 (Core Logic)

### 1. 등장하는 문자 종류 확인

* 두 번째 연산은 문자열에 이미 존재하는 문자끼리만 치환할 수 있다.
* 따라서 두 문자열에 등장하는 문자 종류가 동일해야 한다.

### 2. 문자별 빈도수 비교

* 첫 번째 연산으로 문자의 위치는 자유롭게 변경할 수 있다.
* 두 번째 연산으로 문자별 빈도수 자체를 서로 교환할 수 있다.
* 따라서 각 문자열의 문자 빈도수를 구한 뒤 정렬하여 동일한 빈도 구성을 가지는지 확인한다.

```text
word1: a:2, b:3, c:1
word2: a:1, b:2, c:3

빈도 구성: [1, 2, 3]
```

### 3. 배열을 이용한 빈도 관리

* 문자열은 영문 소문자로만 구성되므로 크기 `26`의 배열을 사용한다.
* 두 문자열의 빈도 배열을 정렬한 뒤 같은 위치의 값이 모두 동일하면 `true`를 반환한다.

---

```text
시간 복잡도: O(n + m)
공간 복잡도: O(1)
```

* 핵심은 **등장하는 문자 종류가 동일하고, 문자별 빈도수의 구성이 동일한지 확인하는 것**이다.
